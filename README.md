# My-projects1.2
# Система хранения данных для предприятия автомобильной отрасли

Учебный проект по проектированию архитектуры системы хранения данных для предприятия, совмещающего автосервис и продажу автомобильных запчастей.

## О проекте

В рамках проекта была разработана модель хранения и обработки данных для предприятия среднего размера, включающего СТО, склад запчастей, отдел продаж и онлайн-канал.

Спроектирована клиент-серверная архитектура с разделением оперативного и аналитического контуров.

## Что реализовано

- исследована предметная область автосервиса и торговли запчастями;
- определены основные бизнес-процессы и информационные потоки;
- разработана логическая модель базы данных;
- спроектирована архитектура системы хранения данных;
- определены связи между клиентами, автомобилями, заказ-нарядами, работами, запчастями, складом и оплатами;
- выбрана PostgreSQL для хранения транзакционных данных;
- предусмотрено объектное хранилище для фотографий и документов;
- спроектирован отдельный DWH для аналитической отчетности;
- описан ETL-процесс передачи данных из OLTP в DWH;
- спроектировано взаимодействие с внешними сервисами через API;
- выполнена оценка нагрузки и роста объема данных;
- определены механизмы резервного копирования и восстановления.

## Архитектура

Основные компоненты:

- клиентские приложения;
- API Gateway;
- сервер приложений;
- PostgreSQL;
- объектное хранилище;
- DWH;
- ETL;
- BI-система;
- сервер резервного копирования;
- внешние сервисы поставщиков и платежных систем.

## Основные сущности

`Customers` — клиенты  
`Vehicles` — автомобили  
`Work Orders` — заказ-наряды  
`Services` — выполняемые работы  
`Parts` — запчасти  
`Inventory` — складские остатки  
`Sales` — продажи  
`Payments` — оплаты  
`Employees` — сотрудники

## Аналитика

Спроектированы аналитические витрины для анализа:

- загрузки ремонтных постов;
- выручки и маржинальности;
- повторных обращений клиентов;
- оборачиваемости склада;
- гарантийных случаев и качества ремонта.

## Технологии и подходы

PostgreSQL, SQL, DWH, ETL, OLTP, REST API, клиент-серверная архитектура, ER-моделирование, проектирование информационных систем.
